## What's fixed in 2.0.1

- Fixed: nothing played from a list, album or playlist ("Couldn't prepare the playlist", "Changes are off in this test host")
- Updates now install themselves while Gatefold is in the background

<!-- gatefold:end -->

### Install

- **New:** run `Gatefold-Setup-2.0.1.exe`. It installs foobar2000 too if needed.
- **Have foobar2000:** open `foo_gatefold-2.0.1.fb2k-component` (or Preferences → Components → Install…).
- **On Gatefold 2.0.0:** press **Update** in the sidebar, or just install `Gatefold-Setup-2.0.1.exe` over it.
- **On Gatefold 1.x:** **Update now** in Gatefold, then **Install Gatefold 2.0**.

The installer is not code-signed yet: if SmartScreen warns, **More info → Run anyway**.

### Что исправлено в 2.0.1

- Исправлено: ничего не играло из списка, альбома или плейлиста («Couldn't prepare the playlist», «Changes are off in this test host»)
- Обновления теперь ставятся сами, пока Gatefold в фоне

Установка: `Gatefold-Setup-2.0.1.exe` (поставит и foobar2000, если его нет) или `foo_gatefold-2.0.1.fb2k-component`, если foobar2000 уже есть. С 2.0.0 — кнопка «Обновить» в боковой панели. С 1.x — «Обновить сейчас», затем «Установить Gatefold 2.0».

Что нового в 2.0 — в [релизе 2.0.0](https://github.com/DEVIROYrus/gatefold-foobar2000/releases/tag/v2.0.0).
