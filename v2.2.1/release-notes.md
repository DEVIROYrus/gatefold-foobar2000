## What's new in 2.2.1

- **Columns:** move, resize and hide any column of playlists and album pages, built-in ones too; hide the column titles
- **Output device:** switch it from the Sound button, right-click for a quick menu
- Play counts without extra components
- Disc titles in multi-disc albums, in playlists too
- Cursor follows playback works
- Autotag picks up where the last check stopped
- Faster search on big libraries
- Freezes on big playlists fixed
- Listening history counts every track, the window minimised too
- Plus many smaller fixes

### Install

- **New:** run `Gatefold-Setup-2.2.1.exe`. It installs foobar2000 too if needed.
- **Have foobar2000:** open `foo_gatefold-2.2.1.fb2k-component` (or Preferences → Components → Install…).
- **On Gatefold 2.2:** Gatefold updates itself.
- **On Gatefold 2.0 or 2.1:** update in Gatefold, then run the installer once: some fixes live in the component.
- **On Gatefold 1.x:** **Update now** in Gatefold, then **Install Gatefold 2.0**.

The headphone equalizer data comes from [AutoEq](https://github.com/jaakkopasanen/AutoEq) (MIT).

The installer is not code-signed yet: if SmartScreen warns, **More info → Run anyway**.
