## What's new in 2.0.2

- Plays are no longer counted twice; doubled plays in your history are cleaned up
- foobar2000's own keyboard shortcuts now work in Gatefold
- foobar2000's right-click menu works on every monitor
- Discography: combine Albums, EPs and Singles; your RELEASETYPE tag decides the type
- Edition names from your tags (EDITION, VERSION) are shown next to the year
- Plus a few smaller fixes

### Install

- **New:** run `Gatefold-Setup-2.0.2.exe`. It installs foobar2000 too if needed.
- **Have foobar2000:** open `foo_gatefold-2.0.2.fb2k-component` (or Preferences → Components → Install…).
- **On Gatefold 2.0.1:** updates by itself while Gatefold is in the background.
- **On Gatefold 2.0.0:** press **Update** in the sidebar.
- **On Gatefold 1.x:** **Update now** in Gatefold, then **Install Gatefold 2.0**.

The installer is not code-signed yet: if SmartScreen warns, **More info → Run anyway**.
