## What's new in 2.1.0

- **Equalizer → Headphones:** tuning for your model from 4800+ AutoEq measurements; four styles, strength, kept per output device
- Tracklist tab on Now Playing
- Cover glow in each cover's own colours
- Genres, styles and moods on Now Playing open all their tracks
- A–Z rail and cover size slider in the Library
- Genres: sub-genres and renaming in files
- Tag editor for tracks and albums
- Artist photos: add, drag in, refresh
- Five custom palettes; save an album's palette into any of them
- Album menu everywhere: refresh artwork, foobar2000 Properties
- Animated covers (cover.gif) and romaji under Japanese lyrics
- Recently added without Playback Statistics; duets count for each artist
- Portable foobar2000, touch and pen, full screen on any monitor
- Settings open over the current screen
- Français
- Plus many smaller fixes

### Install

- **New:** run `Gatefold-Setup-2.1.0.exe`. It installs foobar2000 too if needed.
- **Have foobar2000:** open `foo_gatefold-2.1.0.fb2k-component` (or Preferences → Components → Install…).
- **On Gatefold 2.0.x or a 2.1 beta:** update in Gatefold, then run the installer once: some fixes live in the component.
- **On Gatefold 1.x:** **Update now** in Gatefold, then **Install Gatefold 2.0**.

The headphone equalizer data comes from [AutoEq](https://github.com/jaakkopasanen/AutoEq) (MIT).

The installer is not code-signed yet: if SmartScreen warns, **More info → Run anyway**.
