## What's new in 2.2.0

- **Smart shuffle:** Gatefold picks the order itself; Up next shows the real next tracks
- Spectrum analyzer on Now Playing
- The whole track list of an album you have in part; the missing tracks play from YouTube
- Find tags in MusicBrainz for an album or the whole library, with review and undo
- Tag clean-up: junk removed from names and comments
- Power saving on battery
- Animation frame rate setting
- Pick the album's accent from the cover's colours; palette previews when saving
- Performance optimizations
- Tags can be written to the playing track
- Full screen fixes
- Better album colours
- Cover fixes; mixes of the day refreshed daily
- Plus many smaller fixes

### Install

- **New:** run `Gatefold-Setup-2.2.0.exe`. It installs foobar2000 too if needed.
- **Have foobar2000:** open `foo_gatefold-2.2.0.fb2k-component` (or Preferences → Components → Install…).
- **On Gatefold 2.0 or 2.1:** update in Gatefold, then run the installer once: some fixes live in the component.
- **On Gatefold 1.x:** **Update now** in Gatefold, then **Install Gatefold 2.0**.

The headphone equalizer data comes from [AutoEq](https://github.com/jaakkopasanen/AutoEq) (MIT).

The installer is not code-signed yet: if SmartScreen warns, **More info → Run anyway**.
