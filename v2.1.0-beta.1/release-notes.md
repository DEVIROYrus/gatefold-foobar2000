## What's new in 2.1.0-beta.1

- Tracklist tab on Now Playing
- Cover glow in each cover's own colours
- Genres, styles and moods on Now Playing open all their tracks
- A–Z rail and cover size slider in the Library
- Genres: sub-genres, pinned genres, renaming in files, a list in the sidebar
- Tag editor for tracks and albums
- Artist photos: add, drag in, refresh
- Five more custom palettes; save an album's palette into any of them
- Album menu everywhere: refresh artwork, foobar2000 Properties
- Animated covers (cover.gif) and romaji under Japanese lyrics
- Recently added without Playback Statistics; duets count for each artist
- Portable foobar2000, touch and pen, full screen on any monitor
- Français
- Plus many smaller fixes

### Install

This is a **beta**: Gatefold offers it only on the **Beta** update channel. Back to stable at any time: Settings → Updates → Stable.

- **New:** run `Gatefold-Setup-2.1.0-beta.1.exe`. It installs foobar2000 too if needed.
- **Have foobar2000:** open `foo_gatefold-2.1.0-beta.1.fb2k-component` (or Preferences → Components → Install…).
- **On Gatefold 2.0.x:** update in Gatefold, then run the installer once: some fixes live in the component.

The installer is not code-signed yet: if SmartScreen warns, **More info → Run anyway**.
